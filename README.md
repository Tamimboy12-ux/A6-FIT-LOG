** FitLog — Workout Library

FitLog is a modern and responsive workout library web application where users can explore workouts, view workout details, add exercises to today's plan, and save workouts for later.

** Technologies

* Next.js
* TypeScript
* Tailwind CSS
* DaisyUI
* Lucide React
* REST API
* React Toast

** Features

* Browse workout library with responsive workout cards
* View detailed workout information
* Add workouts to Today's Plan
* Save workouts for later
* My Plan page with live exercise, time, and calorie metrics
* Mark workouts as done or remove them
* Sort workouts by Duration, Calories, and Rating
* Responsive design for mobile, tablet, and desktop
* Custom 404 page for invalid routes

** API

FitLog uses the following API:

`https://api.abcz.workers.dev/api/fitlog`
